# outreach/ — WhatsApp-рассылка первого касания [зона разработчика №2]

**Задача:** отправить каждому лиду **первое** персональное сообщение, после чего
диалог подхватывает ИИ-агент №1.

## ⚠️ Анти-бан (главный риск проекта)

Массовая холодная рассылка нарушает правила WhatsApp → бан номера. Обязательно:
- прогретые номера, старт 10–30 сообщений/день на номер, плавный рост;
- разные тексты, задержки, «человеческий» ритм;
- несколько номеров, распределение нагрузки.

Подробно — в [`../docs/PROJECT_bastau_autopilot.md`](../docs/PROJECT_bastau_autopilot.md), раздел 5.2.

## Канал: GREEN-API

- Отправка: `POST /sendMessage` (`chatId = 77XXXXXXXXX@c.us`).
- После отправки → `status = CONTACTED` в CRM.
- **Входящие ответы клиентов НЕ обрабатывай сам** — webhook GREEN-API этих номеров
  направлен на агента №1 (зона разработчика №1).
